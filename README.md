Objectives
    - To present my personal and educational details.
    - To showcase my technical skills and projects.
    -  To provide links to my resume and GitHub projects.
    -  To make it easy for others to contact me.
Features
    -  Home: Introduces me and my career goal.
    - About Me: Displays my personal and educational information.
    - My Skills: Showcases my programming and web development skills.
    - Projects: Displays my projects with links.
    - Resume: Provides access to my resume.
    -  Contact: Displays my contact information.
Technologies Used
    -  HTML
    -  CSS
    -  JavaScript
How It Works
    -  Open the portfolio website in a web browser.
    -  Navigate through the Home, About, Skills, Projects, and Contact sections.
    -  View my technical skills and project details.
    -  Access my resume and projects using the available links.
Project Structure
    -  index.html – Website structure.
    -  style.css – Website design and styling.
    -  script.js – Interactive functionality.
    -  README.md – Project documentation.
How to Run
    -  Download or clone the GitHub repository.
    -  Open the project folder in Visual Studio Code.
    -  Open index.html in a web browser.
    -  Explore the portfolio sections.
